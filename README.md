# Big CSV Analyzer

Веб-приложение для лабораторной работы **«Работа с Big Data»**. Проект позволяет загрузить большой CSV-файл, выполнить анализ данных, обучить модель машинного обучения и визуализировать результаты через простой веб-интерфейс.

Ссылка на видеодемонстрацию: добавить после записи видео.

## Цель проекта

Разработать простое приложение для работы с большими данными:

- загрузка большого набора данных;
- анализ структуры и качества данных;
- обучение ML-модели после загрузки;
- отображение результатов и графиков в браузере.

## Что умеет приложение

- загружает CSV-файлы через браузер;
- показывает первые строки файла перед анализом;
- позволяет выбрать целевую колонку для обучения модели;
- считает количество строк, колонок, пропусков и числовую статистику;
- автоматически определяет тип задачи:
  - **классификация**, если целевая колонка категориальная или дискретная;
  - **регрессия**, если целевая колонка числовая и непрерывная;
- обучает модель `RandomForestClassifier` или `RandomForestRegressor`;
- показывает метрики модели:
  - `Accuracy` для классификации;
  - `RMSE` и `R2` для регрессии;
- строит визуализации:
  - распределение целевой переменной;
  - корреляционная матрица числовых признаков;
  - важность признаков модели.

## Какие данные можно загружать

Приложение принимает CSV-файлы:

- с расширением `.csv`;
- с названиями колонок в первой строке;
- с числовыми и текстовыми признаками;
- с одной целевой колонкой, которую нужно предсказывать;
- размером до 1 ГБ.

Пример подходящей таблицы:

```text
customer_age,income,monthly_visits,plan,churn
34,87000,10,plus,0
51,123000,4,pro,1
22,45000,12,basic,0
```

Целевая колонка выбирается после загрузки файла. Например:

- `churn` - предсказание ухода клиента, задача классификации;
- `revenue_next_month` - предсказание дохода, задача регрессии.

- метрики модели;
- таблица пропусков;
- числовая статистика;
- графики.

## Как работает обработка больших данных

CSV-файл не загружается целиком в память для первичного анализа. В `app.py` используется чтение чанками:

```python
pd.read_csv(path, chunksize=CHUNK_SIZE)
```

Размер чанка:

```python
CHUNK_SIZE = 50_000
```

Во время прохода по чанкам приложение считает:

- количество строк;
- список колонок;
- типы данных;
- количество пропусков;
- базовую статистику по числовым колонкам.

Для обучения модели и построения графиков сохраняется ограниченная выборка:

```python
SAMPLE_LIMIT = 50_000
```

Такой подход позволяет показать принцип работы с большими данными без загрузки всего файла в оперативную память.

## Машинное обучение

После загрузки CSV пользователь выбирает целевую колонку. Далее приложение:

1. удаляет строки, где целевая колонка пустая;
2. отделяет признаки от целевой переменной;
3. определяет тип задачи;
4. делит данные на train/test;
5. обрабатывает числовые и категориальные признаки;
6. обучает модель Random Forest;
7. считает метрики качества;
8. строит график важности признаков.

Для числовых признаков используется заполнение пропусков медианой. Для категориальных признаков используется заполнение наиболее частым значением и one-hot encoding.

## Возможные проблемы

### Порт 5000 занят

Запустите приложение на другом порту:

```bash
PORT=5001 python3 app.py
```

### CSV не загружается

Проверьте, что:

- файл имеет расширение `.csv`;
- первая строка содержит названия колонок;
- файл не превышает 1 ГБ;
- данные разделены запятыми.

### Модель не обучается

Проверьте, что:

- выбрана правильная целевая колонка;
- в целевой колонке достаточно заполненных значений;
- кроме целевой колонки есть другие признаки.
